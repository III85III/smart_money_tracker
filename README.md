<a name="english"></a>
## English
**Smart Money Tracker** is a data analysis tool designed to track large transactions and market movements, helping users identify "smart money" behavior.

### Features
- **Transaction Analyzer:** Parses and processes large volume transactions.
- **Data-Driven Insights:** Provides logical analysis of market trends.
- **Local Storage:** Securely manages data in local files without leaking to Git.

### Setup & Run
Run `setup.bat` to automatically install dependencies and launch the tracker.

## فارسی
**ردیاب پول هوشمند (Smart Money Tracker)** ابزاری برای تحلیل داده‌های معاملاتی است که به کاربران کمک می‌کند تراکنش‌های بزرگ و حرکات نهنگ‌های بازار را شناسایی کنند.

### قابلیت‌ها
- **تحلیلگر تراکنش:** پردازش و شناسایی تراکنش‌های با حجم بالا.
- **بینش داده‌محور:** ارائه تحلیل‌های منطقی از روند بازار.
- **امنیت داده‌ها:** مدیریت داده‌ها به صورت محلی و جلوگیری از لو رفتن اطلاعات در گیت‌هاب.

### نحوه اجرا
کافیست فایل `setup.bat` را اجرا کنید تا پیش‌نیازها خودکار نصب شده و ابزار اجرا شود.
